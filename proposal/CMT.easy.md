# 🦶 CMT — 발끝부터 망가지는 유전성 신경병, 그 "치료" 설계

> **CMT = 샤르코-마리-투스병**(Charcot-Marie-Tooth) · 유전성 말초신경병.
> 별칭: **"발끝부터 시드는 병"**
> 모든 수치는 in-silico(계산) 설계·문헌 기반이며, **임상은커녕 wet-lab 검증도 아직**입니다(정직).

---

## 🦶 CMT — "발끝부터 시드는 병"

- **하는 일(병)**: 다리·손의 말초신경이 서서히 망가져 **발·종아리 근육이 마르고**, 발 모양이 변하고(요족), 걸음·손놀림이 둔해지는 유전병. 2,500명에 1명꼴(가장 흔한 유전성 신경병)인데 — **승인된 근본 치료제가 0개**.
- **비유**: 집 안 **전선 피복(절연)**이 끝쪽부터 닳아 벗겨지는 것 — 신호가 새고 약해져 가장 먼 방(발끝)부터 불이 안 들어옴.
- **왜 우리가**: 가장 흔한 유전성 신경병인데도 근본 치료제가 아직 0개 — 빈 땅이 분명한 미충족 난제라서.

```
정상 신경                    CMT 신경
─────────────              ─────────────
 ▣▣▣ 피복 멀쩡   →          ▣▣░ 끝쪽 피복 닳음
 ⚡ 신호 쌩쌩      →          ⚡··· 신호 약함·느림
 발끝까지 도달    →          발끝 먼저 꺼짐(근위축)
```

---

## 우리가 한 것 — "남들 안 가본 길 찾기"

CMT는 표적(망가지는 부위)이 여러 종류입니다(PMP22·MFN2·GJB1·HDAC6·SARM1 …). 우리는 컴퓨터로
각 표적에 약이 붙는지 무료로 따져봤고, **무엇이 이미 레드오션이고 무엇이 진짜 빈 땅인지**를 정직하게 갈랐습니다.

```
표적                  남들 상황            우리 판정
──────────────────────────────────────────────────
HDAC6                Phase 1 경쟁중       🔴 레드오션 (방법검증만)
ClC-1               Phase 2a 경쟁중       🔴 레드오션
SARM1·MFN2          경쟁약 있음           🔴 레드오션 (포켓 교정해 정합성만)
★ GJB1 / Cx32       경쟁=유전자치환뿐     🟢 유일하게 열린 땅
```

### ★ 핵심 발견 후보 — GJB1-RESCUE "구겨진 자리에만 생기는 손잡이"

- **하는 일**: CMT 변이로 **잘못 접힌 단백질(Cx32)**을 작은 분자가 붙들어 다시 제대로 접히게(약리적 샤페론).
- **비유**: 멀쩡한 상자엔 손잡이가 없는데, **찌그러진 상자에만 쥘 홈이 패임** — 그 홈에 맞는 쐐기(약)를 끼워 모양을 잡아줌.
- **계산이 보여준 것(in-silico 1라운드, 무료)**:
  - 실제 인간 Cx32 구조 확보(고해상도) — 추정 모델 불필요
  - 가장 심한 변이 **L143P**가 단백질을 압도적으로 불안정화
  - **그 변이가 있을 때만 새로 열리는 빈틈(숨은 포켓)** 발견 → 변이체만 골라 잡을 천연 근거
  - 그 빈틈에 잘 맞는 후보를 골라냄(임상 화학샤페론 4-PBA보다 우수, 대조군은 약하게 — 판별 정상)
- **vs 경쟁**: 다들 망가진 유전자를 **통째로 교체**(유전자치료). 우리는 **변이가 만든 홈**을 노림 → 그래서 빈 땅.

## 정직한 현재 상태 (d6 · 절대 과장 금지)

```
어디까지 왔나 (사다리)
─────────────────────────────
[✔] 표적 지도 + 신규성 판별        ← 완료
[✔] GJB1 구조·변이·포켓·도킹(1라운드) ← 완료 (scaffold 수준)
[ ] 막(POPC) 환경 정밀 결합력(ABFE)  ← 다음 (무료 GPU 대기)
[ ] wet-lab: 실제 trafficking 복구    ← 미착수
[ ] 임상                             ← 한참 멀음
```

- **이건 "발견"이 아니라 "좌표"입니다** — 신규성·기전은 아직 **PENDING**(검증 falsifier 통과 전).
- 모든 분자는 **scaffold(뼈대) 수준 placeholder** — 약물 후보가 아니라 "어디에·어떤 모양이 맞나"의 좌표.
- CMT는 **인류가 아직 한 명도 정상 등정 못 한 산**(승인 치료 0) — 그래서 의미는 있지만, 숫자를 "성공"이라 부르지 않습니다.
