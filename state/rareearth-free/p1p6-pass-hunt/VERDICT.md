## The three structural reasons the intersection is empty

1. **Already-PASS ⇒ already-commercial (not novel):** KSF:Mn4+ red phosphor, InP QD green/red, Cr3+ NIR phosphor, AB2-Laves NiMH, Phinesse FCC, ceria-coated-silica — all clear the physics and SHIPPED. Re-confirming them reproduces a known result (d_novel_only avoidance target).
2. **Novel ⇒ fails P1 or P2:** all-d Heusler (P1, needs 5T), Mn2+/Bi3+ green phosphor (P1), Mg-doped NBT (P1/P2), Cu-Mn TWC (P1), MgH2 (P1 thermodynamics), CsPbBr3 scintillator (P2 Pb), Mn-PyC3A MRI (P2 Mn safety + P5).
3. **Supply-chain swap-trap (P6 own-goal):** the deepest meta-finding — substituting a critical element RELOCATES the dependence rather than eliminating it. Optical glass La→Nb/Ta (more concentrated); SOFC RE→Bi/Ga/Sc/In (all China chokepoints, export-controlled 2023-25); NiMH La→V; TWC Cu-Mn→Nb. The only domain where this trap is absent is H2 storage — because its incumbents (TiFe/MgH2/AB2) were NEVER RE-locked, so "RE substitution" is a non-problem there.

## CLOSEST NEAR-MISS

**MnFe(P,Si)** — passes P1/P2(borderline)/P3/P4/P6; the ONLY RE-free, As-free, fully-scalable, cheap, no-new-critical-element magnetocaloric. Single blocking gate = **P5** (no qualified shipping product). The block is downstream economics (NdFeB ~2T field + COP vs vapor compression), not a materials wall — so it is the candidate most likely to flip if a system-level breakthrough (stronger field source / cascade regenerator economics) lands. Note: NOT a novel discovery (patented since ~2002), so it is "undeployed product," not "novel material."
