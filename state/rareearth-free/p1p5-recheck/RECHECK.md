## (3) HONEST VERDICT (g0 / d6 — no tune-to-green)

**With P6 EXCLUDED, the set {genuinely-novel ∩ undeployed ∩ pass P1–P5} is still EMPTY.**

This is the decisive, non-obvious finding: **P6 was NOT the sole blocker.** The intuition that "P6 is the hardest gate that keeps everything out" is *false* under audit — removing it rescues nobody, because the campaign's near-misses split cleanly into two disjoint failure classes that P6-removal does not touch:

1. **PASS P1–P5 ⇒ already-commercial (novelty-fail).** Every candidate clean enough to clear the five technical gates is already in the market (the separability meta-law L16: market substitution boundary = physics separable boundary). For these, P6 was the gate that flagged the *relocated dependence*, but novelty already disqualified them — so dropping P6 changes nothing.
2. **Novel ⇒ fails P1/P2/P3/P5 before P6 is ever reached.** Tetrataenite (P1 ordering wall + P3 bulk), Fe16N2 (P1 Hc + P2 metastable + P3 powder), all-d Heusler (P1 5-T field), BZI/Mg-NBT (P1 conductivity), Ac-225 (P3 Th-229 feedstock cap), Mn-MRI (P2 toxicity + P5). These never get to P6.

The closest geometry to a "P6-only" candidate is the **magnet corner**, where SmCo5/Sm2Co17 and the optical-glass Nb-niobate are the only rows whose *prior* first-fail was literally P6. But both are **already-commercial incumbents** (SmCo since the 1970s; N-LASF glass shipping), so excluding P6 reclassifies them as "technically deployable" — which they already ARE — not as a novel discovery. They are not members of the {novel} set.

### Each "would-survive-if-only-P6" candidate's actual P6 dependence (for completeness)
Even though none is novel, the P6 dependence each *would* relocate is real and worth recording:
- **SmCo5/Sm2Co17** → Sm (China ~99% separation) + Co (DRC ~76% mine / China ~70% refine) — stacks TWO chokepoints.
- **Nb2O5 niobate optical glass** → Nb (~77% CBMM/Brazil single-supplier) — *more* concentrated than the La it replaces (swap-trap).
- **Ta/Nb-LLZO** → Ta (3TG conflict-mineral) / Nb, AND still contains La (rare-earth) — disqualified twice.
- **AB2-Laves NiMH** → V (vanadium) — new dependence; also the application itself displaced by Li-ion.

**Bottom line:** P6 is the *most-final* gate in presentation order, but it is *redundant* in effect — it never holds the line alone. The empty intersection is structural (separability meta-law), not an artifact of an over-strict supply-chain gate. Confirms magnet 0/11 and non-magnet 0/7+ with the supply-chain dimension explicitly factored out.
