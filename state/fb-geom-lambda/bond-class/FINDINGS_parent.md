# bond-class r1 (parent-persisted) · g5 PASS · CRITICAL discriminator
"bond-stretch mode" ≠ "off-diagonal coupling". Three conflated:
1. TRUE off-diagonal SSH (∂t/∂u modulates HOPPING → kinetic → LIGHT bipolaron) ← recipe target
2. bond-stretch but band-DIAGONAL (MgB2 E2g, B-diamond, B-C clathrate) = Holstein/ME class = Regime I CLOSED (NOT escape)
3. Holstein on-site (C60 JT) = heaviest
→ MgB2 / B-doped diamond / SrB3C3 / MB2C8 are bond-STRETCH but band-DIAGONAL → conventional ME, do NOT escape ceiling.

Ranked off-diagonal+light shortlist:
1 bond-SSH/Peierls bipolaron lattices — cleanest off-diagonal, light by construction, Tc=QMC(λ=α²/3Ωt); but MODELS not a real host → NOVEL target to realize.
2 Graphene Kekulé / twisted-bilayer optical-SSH (oSSH) — real C, mechanism IS hopping modulation, lightest, flat-band variants connect to flat-band requirement = STRONGEST real-material off-diagonal candidate.
3 Organic molecular semiconductors (rubrene/pentacene) — nonlocal Peierls dominant (transient localization), ∂t/∂u DFT-quantified; real, open Q = drive SC.
4 κ-(BEDT-TTF)2X — real SC Tc~10K but Holstein co-essential (not cleanly off-diagonal).
5 trans-polyacetylene — definitional SSH but small λ (anchor not target).

HONEST (d6): no class is cleanly off-diagonal-dominant AND real light-atom AND known SC simultaneously.

(graphene Kekulé/TBG or rubrene/organic) → downfold bond-Peierls ∂t/∂u + U → bipolaron-mass → Tc.
