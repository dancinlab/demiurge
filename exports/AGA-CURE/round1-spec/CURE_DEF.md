# AGA-CURE spec — 완치 정의 + 재생 가역성 맵 (round-1 Lane 1)

## 왜 "있는→없는" 완전복원이 원리적으로 가능한가 (AGA = non-scarring)
- Bald scalp는 **KRT15+ 모낭 줄기세포(bulge HFSC) reservoir를 보존**한다 — 사라진 게 아니라 휴면. (Garza 2011, PMC3026732)
- 결함은 reservoir가 아니라 **CD200+/CD34+ 전구세포(progenitor) 활성화/증식 고장** — 줄기세포는 멀쩡, 전구세포만 손상.
- 가역성은 **arrector pili muscle(APM)–bulge 부착**에 달림: 부착 유지 → 가역, 탈착 → 비가역/부분.
- 2026 Nat Commun: 남성 AGA 성장지연을 **connective tissue sheath(CTS) 비정상 수축**이 매개 → 니치(기계적) 표적 추가.

## 가역성 3-tier (cure 난이도 등급 · arm 매핑)
| tier | 상태 | 복원 경로 |
|---|---|---|
| T1 가역 | APM-bulge 부착 · vellus 축소 · 줄기/전구 보존 | arm② 되돌리기(Wnt) + arm① 깨우기 |
| T2 부분 | APM 탈착 · CD200/CD34 전구 소실 | arm① 깨우기(전구 재생) + 니치/CTS 재건 |
| T3 비가역 | 모낭 완전소실 · CTS 섬유화 | arm④ de novo neogenesis 필수 |

## CURE 게이트 (완치 정량 정의 — in-silico)
완치 = "있는→없는" = 다음 ALL_PASS (비-wet-lab in-silico 모델 기준):
1. **terminal 밀도 복원**: 탈모부 terminal hair/cm² → 후두부(never-bald) 기준의 ≥90% 회복
2. **miniaturization index 정상화**: terminal:vellus 비 → never-bald 기준 복귀 (anagen% 정상)
3. **재발 0 (durable)**: 약물 중단/모델 steady-state 후에도 재-miniaturization 없음 (arm③ 영구잠금)
4. **T3 영역 신생**: 완전소실 영역에서 de novo 모낭 형성 > 0 (arm④)
→ 1-3 = T1/T2 복원(SoC 초월), 4 = T3 신생. 4개 모두 = 진정한 "없는 사람" 전환.

## SoC 대비 (왜 기존 약은 cure 아님)
미녹시딜/피나 = 유지·완만한 역전(terminal 부분 회복, 중단 시 재발) → 게이트 1만 부분 충족, 3·4 미달.
AGA-CURE = 1-4 전부 → disease-modifying 완치.
